J.A.R.V.I.S.

A real-time voice AI that hears, sees, speaks and controls your computer, on Windows, macOS and Linux. It runs on your own machine: Gemini Live, or your own local models.

View on GitHub Quick start

What it does

Background tasks

Long work runs beside the conversation, saved after every step and picked up again after a restart. You can steer it by voice.

Deep research

Reads sources in full, checks every quote against the saved page and writes a cited report in your language.

Routines & quiet hours

Briefings, check-ins, news watch and reminders all run on one schedule engine that you change by talking to it.

Choose your engine

Gemini Live, or your own STT + LLM + TTS: Ollama, LM Studio, OpenAI, Groq and more. Whisper and Piper run offline.

System control

Apps, windows, volume, browser, files and messages. Every action reports what it actually checked.

Command-center HUD

Glass panels, live gauges, a 3-D reactor core or a lip-synced holographic face, drawn in software.

Memory & undo

Remembers what matters, shows you everything it has stored, and can undo the file and setting changes it made.

Plugins

Drop one .py file into plugins/ and the assistant gains a new skill on its next launch.

Quick start

git clone https://github.com/thengsahil-oss/jarvis-2.git
cd jarvis-2
python setup.py   # installs what YOUR OS needs
python main.py

Runs locally, not in the browser. JARVIS is a desktop application. It needs your microphone, speakers and screen. The phone dashboard is served by the app on your own network once it's running.

Requirements

OSWindows 10/11, macOS, or Linux (X11 for full desktop control)
Python3.11, 3.12 or 3.13
AudioMicrophone and speakers
API keyA free Gemini key for the Gemini engine. A fully local setup needs none
GPUNot required anywhere
